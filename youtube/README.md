## Launch plan
1. Day 1, 7:30 PM IST — publish **Short #1** (How Machines Learned to Talk).
2. Day 3, 7:30 PM IST — publish **Short #2** (Tata legends). Link each as the other's *Related video*.
3. After 48 h, compare *Viewed vs. swiped away* in YouTube Studio: a hook problem shows there first; keep whichever opening works better for the next videos.
4. Post consistently (2–3 Shorts a week) — the algorithm rewards a steady new channel more than one big upload.
